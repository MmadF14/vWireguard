# vWireguard

vWireguard یک رابط مدیریت تحت وب قدرتمند برای VPN وایرفارد (WireGuard) است که برای ارائه داشبورد ساده و کاربردی جهت مدیریت سرور و کلاینت‌های شما طراحی شده است. این داشبورد به طور کامل با استفاده از TailwindCSS بازطراحی شده و رابط کاربری مدرن و واکنش‌گرایی را ارائه می‌دهد.

## 🌟 ویژگی‌های کلیدی

- **داشبورد مدرن**: رابط کاربری کاملاً بازطراحی شده با استفاده از TailwindCSS و الهام گرفته از اصول طراحی مدرن.
- **پشتیبانی دو زبانه**: پشتیبانی کامل از زبان‌های انگلیسی (LTR) و فارسی (RTL).
- **حالت تاریک/روشن**: قابلیت تغییر آسان بین تم‌های تاریک و روشن.
- **طراحی واکنش‌گرا**: بهینه‌سازی شده برای تمام دستگاه‌ها، از دسکتاپ تا گوشی‌های موبایل.
- **مدیریت کاربران**: کنترل دسترسی مبتنی بر نقش (ادمین، مدیر، کاربر).
- **مدیریت کلاینت‌ها**: افزودن، ویرایش و حذف آسان کلاینت‌های وایرفارد. تولید کدهای QR و فایل‌های پیکربندی.
- **پیکربندی سرور**: مدیریت تنظیمات رابط شبکه وایرفارد مستقیماً از طریق داشبورد.
- **نظارت در زمان واقعی**: پایش منابع سیستم (CPU، RAM، دیسک) و ترافیک شبکه به صورت لحظه‌ای.
- **Wake-on-LAN**: روشن کردن دستگاه‌های شبکه از راه دور.
- **ابزارهای سیستمی**: ابزارهای داخلی برای نگهداری و عیب‌یابی سیستم.

## 🚀 نصب

### نصب سریع (توصیه شده)

vWireguard را تنها با یک دستور نصب کنید. نصب‌کننده به صورت خودکار آخرین نسخه باینری را دانلود کرده، سرویس systemd را تنظیم می‌کند و محیط را پیکربندی می‌نماید.

```bash
bash <(curl -Ls https://raw.githubusercontent.com/MmadF14/vwireguard/master/install.sh)
```

**نیازمندی‌ها:**
- لینوکس (amd64 یا arm64)
- دسترسی روت (Root)
- سیستم مبتنی بر systemd
- اتصال اینترنت

### نصب دستی (ساخت از سورس)

اگر ترجیح می‌دهید برنامه را از کد منبع بسازید یا نیازهای خاصی دارید:

1.  **نصب پیش‌نیازها**:
    -   Go نسخه 1.21 یا بالاتر
    -   WireGuard (`wireguard`, `wireguard-tools`)
    -   Git

2.  **دریافت مخزن (Clone)**:
    ```bash
    git clone https://github.com/MmadF14/vwireguard.git
    cd vwireguard
    ```

3.  **ساخت برنامه**:
    ```bash
    go build -o vwireguard
    ```

4.  **اجرا**:
    ```bash
    ./vwireguard
    ```
    (نکته: برای محیط عملیاتی، توصیه می‌شود یک سرویس systemd ایجاد کنید.)

## 🛠️ پیکربندی

### نام کاربری و رمز عبور پیش‌فرض
- **نام کاربری:** `admin`
- **رمز عبور:** `admin`

**مهم**: لطفاً بلافاصله پس از اولین ورود، رمز عبور پیش‌فرض را تغییر دهید!

### دسترسی به رابط وب
به طور پیش‌فرض، داشبورد در آدرس زیر در دسترس است:
```
http://YOUR_SERVER_IP:5000
```

## 💻 مدیریت با خط فرمان (`vwg`)

vWireguard شامل ابزار خط فرمان `vwg` برای مدیریت سرویس است که به صورت خودکار با نصب‌کننده سریع نصب می‌شود.

```bash
# شروع سرویس
sudo vwg start

# توقف سرویس
sudo vwg stop

# راه‌اندازی مجدد سرویس
sudo vwg restart

# بررسی وضعیت سرویس
vwg status

# مشاهده لاگ‌ها (برای مشاهده زنده از -f استفاده کنید)
vwg log
vwg log -f

# به‌روزرسانی به آخرین نسخه
sudo vwg update
```

## 🔒 امنیت

- **هشینگ رمز عبور**: تمام رمزهای عبور کاربران با استفاده از bcrypt به صورت ایمن هش می‌شوند.
- **کنترل دسترسی مبتنی بر نقش**: کنترل دقیق بر روی مجوزهای کاربران.
- **مدیریت کلید امن**: کلیدهای وایرفارد به صورت ایمن تولید و ذخیره می‌شوند.
- **پشتیبانی HTTPS**: برای محیط‌های عملیاتی توصیه می‌شود (می‌توانید از طریق پروکسی معکوس مانند Nginx یا Caddy پیکربندی کنید).

## 🆘 عیب‌یابی

اگر با مشکلی مواجه شدید، لطفاً به [راهنمای عیب‌یابی](docs/TROUBLESHOOT.md) مراجعه کنید.

بررسی‌های رایج:
1.  اطمینان حاصل کنید که WireGuard نصب شده و ماژول کرنل بارگذاری شده است.
2.  لاگ‌های سیستم را با استفاده از `vwg log` بررسی کنید.
3.  تنظیمات فایروال را بررسی کنید تا ترافیک روی پورت وایرفارد (پیش‌فرض UDP 51820) و پورت داشبورد (TCP 5000) مجاز باشد.
